## DESCRIPTION
This system is designed to facilitate UiTM students in tracking their internship applications efficiently. It acts as a centralized dashboard to manage internship listings, monitor application statuses, and view progress analytics.

## FEATURES INCLUDED
* **Authentication:** Login page with validation.
* **Forgot Password:** Users can simulate a password reset by entering their email and setting a new password (data is saved locally).
* **Dashboard:** Comprehensive summary with 4 interactive charts (Status, Listings, Monthly Activity, Locations).
* **Internship Listings:** Manage and view available internship opportunities (Open/Closed).
* **Application Tracker:** Track application status (Pending, Accepted, Rejected) with real-time updates.
* **User Profile:** View and update student profile information.
* **Responsive Design:** Fully functional on both desktop and mobile devices.
